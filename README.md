# Food Order

Website đặt món ăn trực tuyến, hỗ trợ giỏ hàng, đặt hàng COD và quản trị sản phẩm, đơn hàng.

## Công nghệ

Java 21, Spring Boot 4.0.8, Spring MVC, Thymeleaf, Spring Security, Spring Data JPA/Hibernate, MySQL và Maven Wrapper.


## Cách chạy
Mở PowerShell tại thư mục project và chạy:
bash mvnw spring-boot:run

   Truy cập http://localhost:8080.

## Tài khoản và chức năng

- **USER:** đăng ký trên website; tài khoản mới được cấp `ROLE_USER`,.
- **ADMIN:** tài khoản development có username `admin`, mật khẩu 12345
